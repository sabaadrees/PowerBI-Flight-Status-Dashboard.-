# ✈️ Flight Status Dashboard — Power BI

## Overview
Power BI dashboard analyzing 2M flights across 
10 major US cities — covering total flights, 
delays, and cancellations.

## Key Insights
- Atlanta has the most flights (346K)
- United Airlines has highest delay rate (53.5%)
- 58% On-Time | 40.6% Delayed | 1.5% Cancelled
- Airline/Carrier is the top cancellation reason

## Tools Used
- Power BI Desktop
- DAX Measures
- Data Visualization & Dashboard Design
